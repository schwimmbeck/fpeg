# E402 Grammar too large

A grammar exceeds a limit on its size: more than 1000 instances of templates, instances that expand into more than 100,000 expressions together, more than 64 flags, more than 65,535 field or capture names, a rule without a node of its own that passes on more than 1000 fields to the node around it, or a grammar text too long to read. The limits keep the work of reading a grammar bounded, whatever the grammar.

Each instance of a template is a rule of its own, so a template whose arguments grow with every use expands without end.

```fpeg
start: t<"b">
t<x>: "a" t<x x> | x
```

```text
grammar.fpeg:2:11: error[E402]: the instances of t expand into too many expressions
```

Pass arguments that do not grow, or write the repetition with an operator.

```fpeg
start: t<"b">
t<x>: "a" t<x> | x
```
