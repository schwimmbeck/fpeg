# E310 Builder arguments that do not fit

The arguments of a value builder do not fit: the built-in builders such as `int` and `list` take none, a keyword can be given once, and positional arguments come before keywords.

```fpeg
start: NUMBER
NUMBER: [0-9]+ => int(10)
```

```text
grammar.fpeg:2:19: error[E310]: the builder int takes no arguments
```

Write a built-in builder alone, or call a function of your own with the arguments.

```fpeg
start: NUMBER
NUMBER: [0-9]+ => int
```
