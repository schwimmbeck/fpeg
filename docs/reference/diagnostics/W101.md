# W101 Alternative that is never tried

An alternative stands after one that cannot fail. A choice takes the first alternative that matches, so it never comes to what stands after an alternative that matches everywhere: an optional expression, a repetition that may be empty, the empty string. The same holds after an expression with an error label, which ends the parse where it does not match, and for the levels of a precedence block after a level whose last alternative cannot fail.

```fpeg
start: sign NUMBER
sign: "-"? | "+"
NUMBER: [0-9]+
```

```text
grammar.fpeg:2:14: warning[W101]: this alternative is never tried, since the one before it cannot fail
```

Put the alternative that cannot fail last, or say once what is optional, around the choice.

```fpeg
start: sign NUMBER
sign: ("-" | "+")?
NUMBER: [0-9]+
```
