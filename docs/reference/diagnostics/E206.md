# E206 Wrong number of arguments

A use of a rule with parameters passes another number of arguments than the rule declares, or a level or a parameter is given arguments, which they do not take.

```fpeg
start: list<"a">
list<item, separator>: item (separator item)*
```

```text
grammar.fpeg:1:8: error[E206]: list takes 2 arguments, 1 given
```

Pass one argument for each parameter.

```fpeg
start: list<"a", ",">
list<item, separator>: item (separator item)*
```
