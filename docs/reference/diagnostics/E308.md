# E308 Count out of range

A repetition `e{n,m}` has a maximum below its minimum, or `%tabs` sets a width outside 1 to 1000.

```fpeg
start: "a"{3,2}
```

```text
grammar.fpeg:1:8: error[E308]: a repetition's maximum is below its minimum
```

Write the smaller count first.

```fpeg
start: "a"{2,3}
```
