# E205 Invalid name

A rule name does not start with a letter after its leading underscores. The letter decides whether the rule is syntactic or a terminal, so a name must have one.

```fpeg
start: _1
_1: "a"
```

```text
grammar.fpeg:2:1: error[E205]: the name _1 must start with a letter after any underscores
```

Start the name with a letter after the underscores.

```fpeg
start: _one
_one: "a"
```
