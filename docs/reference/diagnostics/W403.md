# W403 Recovery for a label that nothing raises

A `%recover` directive names a label that no expression raises with `^`, so its recovery never runs, and an error that was meant to recover ends the parse. Mostly the label is misspelled, in the directive or where it is raised.

```fpeg
start: "[" (item ("," item)*)? ("]" ^ close)
item: [0-9]+
%recover clsoe: ()
```

```text
grammar.fpeg:3:10: warning[W403]: no expression raises the label clsoe, so its recovery never runs
```

Name the label as the expression that raises it does.

```fpeg
start: "[" (item ("," item)*)? ("]" ^ close)
item: [0-9]+
%recover close: ()
```
