# E102 Invalid escape

A literal or a character class uses a backslash escape the language does not define. Literals know `\\`, `\"`, `\'`, `\n`, `\r`, `\t`, `\0`, `\xHH` and `\u{H...}`, and classes also `\[`, `\]`, `\-` and `\^`.

```fpeg
start: "\q"
```

```text
grammar.fpeg:1:8: error[E102]: invalid escape
```

Write the character itself, or a defined escape, such as `\\` for a backslash.

```fpeg
start: "\\q"
```
