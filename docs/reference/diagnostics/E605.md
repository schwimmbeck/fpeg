# E605 Misplaced inherited alternatives

`...` stands for the alternatives of the rule that a rule replaces in a grammar it extends: as a whole alternative of the replacing rule, at most once, without an alias, and with the parameters of the rule it replaces. Anywhere else it stands for nothing. In a precedence block, or for one, it is not supported yet ([E501](E501.md)).

```fpeg
%extends "json"
?value: "nan" ...
```

```text
grammar.fpeg:2:15: error[E605]: ... stands only as a whole alternative
```

Write the inherited alternatives as an alternative of their own, before or after the new ones.

```fpeg
%extends "json"
?value: "nan" | ...
```
