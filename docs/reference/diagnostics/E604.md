# E604 Not in the grammar imported

The grammar imports a rule that the other grammar does not define.

```fpeg
%import common (NUMBR)
start: NUMBR+
%ignore " "+
```

```text
grammar.fpeg:1:17: error[E604]: the grammar common defines no rule NUMBR
```

Name a rule the grammar defines. The page of [modules](../grammar.md#modules) lists those of `common`.

```fpeg
%import common (NUMBER)
start: NUMBER+
%ignore " "+
```
