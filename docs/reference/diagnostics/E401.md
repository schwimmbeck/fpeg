# E401 Nesting too deep

An expression nests deeper than 100 levels, counting every operator and group, or an argument of a template grows deeper than that with each instance, or the grammar text nests too deeply to read at all, or grammars extend and import each other more than 64 deep. Every pass over a grammar follows its nesting, so a limit keeps all of them safe on any grammar.
