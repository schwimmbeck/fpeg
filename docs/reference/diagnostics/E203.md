# E203 Unknown attribute

A rule carries an attribute the language does not define. The attributes are `@lexical`, `@reserved`, `@sync`, `@memo` and `@nomemo`.

```fpeg
@inline
start: "a"
```

```text
grammar.fpeg:1:2: error[E203]: unknown attribute @inline
```

Remove the attribute, or use one the language defines.

```fpeg
start: "a"
```
