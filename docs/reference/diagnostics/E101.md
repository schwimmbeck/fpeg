# E101 Syntax error

The grammar text does not follow the [syntax of grammars](../grammar.md). The message lists what could have followed where reading stopped. Reading goes on at the next line that starts a rule or a directive, so that each mistake gets an error of its own.

```fpeg
start: "a" |
```

```text
grammar.fpeg:1:13: error[E101]: expected "!", "%def", "%error", "%if", "%indent", "%off", "%on", "%ref", "%same", "&", "(", ".", "...", "~", character class, literal, name, property class
```

An alternative must follow every `|`. Complete it, or remove the `|`.

```fpeg
start: "a" | "b"
```
