# E202 Undeclared flag

`%on`, `%off` or `%if` names a flag that no `%flag` declares.

```fpeg
start: %on(nested, item)
item: %if(nested) "a"
```

```text
grammar.fpeg:1:12: error[E202]: the flag nested is not declared with %flag
grammar.fpeg:2:11: error[E202]: the flag nested is not declared with %flag
```

Declare the flag.

```fpeg
%flag nested
start: %on(nested, item)
item: %if(nested) "a"
```
