# E309 Builder without a place

A value builder stands where nothing takes its value. An alternative of a rule `_name`, or of a precedence level without `->`, makes no node of its own. A terminal makes tokens, which have no children for `list`, `tuple`, `dict` or `*` and no fields, and all its tokens share one kind, so its alternatives must give one builder.

```fpeg
start: _pair
_pair: NAME "=" NAME => list
NAME: [a-z]+
```

```text
grammar.fpeg:2:25: error[E309]: the builder of _pair has no node to make a value of, since the alternative makes none
```

Give the builder to a rule that makes a node, or give the alternative a node of its own with `->`.

```fpeg
start: pair
pair: NAME "=" NAME => list
NAME: [a-z]+
```
