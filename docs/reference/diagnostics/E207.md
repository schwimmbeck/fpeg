# E207 Unknown field in a builder

A value builder names a field that its alternative cannot hold, in the alternative itself or in the rules it inlines. The builder would get nothing for it on every node, which is a typo or a field of another alternative.

```fpeg
start: key=NAME "=" NAME => pair(key, value)
NAME: [a-z]+
%ignore " "+
```

```text
grammar.fpeg:1:39: error[E207]: the builder of start names the field value, which its alternative cannot hold
```

Give the item the field, or leave the field out of the builder.

```fpeg
start: key=NAME "=" value=NAME => pair(key, value)
NAME: [a-z]+
%ignore " "+
```
