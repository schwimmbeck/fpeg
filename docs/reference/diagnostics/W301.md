# W301 Transparent alternative whose shape depends on the input

An alternative of a transparent rule `?name` gives way to its child where a match leaves exactly one visible child, and makes a node `name` otherwise. This alternative does both, depending on the input. So what stands in the tree at that place is a node for one input and the child for another, and code that reads the tree has to handle both without the grammar saying which to expect.

```fpeg
start: sum
?sum: NUMBER ("+" NUMBER)*
NUMBER: [0-9]+
```

```text
grammar.fpeg:2:7: warning[W301]: this alternative makes a node sum for some inputs and gives way to its one child for others
```

Write one alternative for each shape. An alternative with an alias always makes its node, and can have fields.

```fpeg
start: sum
?sum: terms=NUMBER ("+" terms=NUMBER)+ -> sum | NUMBER
NUMBER: [0-9]+
```

The warning counts the visible children that a match can leave: none, one or several. A rule with parameters is not reported, since the count depends on its arguments.
