# E302 Form that does not fit the rule

A rule carries a form that its kind does not have, or two that exclude each other:

- a terminal cannot be transparent with `?`, since it produces one token and never a node, and an inlined rule `_name` cannot, since it never produces a node of its own,
- a terminal cannot be `@lexical`, since lexical rules produce nodes,
- an alternative of a terminal cannot have an alias `->`, since there is no node to name,
- only a terminal can be `@reserved`,
- only a terminal can have a display name, since an error names tokens and never nodes,
- no rule can be both `@memo` and `@nomemo`.

```fpeg
start: NAME
?NAME: [a-z]+
```

```text
grammar.fpeg:2:2: error[E302]: the terminal NAME cannot be transparent
```

Remove the form, or make the rule a syntactic rule with a lowercase name.

```fpeg
start: NAME
NAME: [a-z]+
```
