# E103 Unknown Unicode property

A `\p{...}` or `\P{...}` names a property the language does not support. The supported properties are `XID_Start`, `XID_Continue`, `Alphabetic`, `White_Space`, `Uppercase` and `Lowercase`.

```fpeg
start: \p{Emoji}
```

```text
grammar.fpeg:1:8: error[E103]: unknown Unicode property Emoji
```

Use a supported property, or list the code points in a class.

```fpeg
start: \p{Alphabetic}
```
