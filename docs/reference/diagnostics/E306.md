# E306 Empty literal

A literal holds no character. The empty string is written `()`, so that an empty literal can never stand by mistake.

```fpeg
start: "a" ""
```

```text
grammar.fpeg:1:12: error[E306]: a literal cannot be empty, use () for the empty string
```

Write `()` for the empty string, or remove the literal.

```fpeg
start: "a" ()
```
