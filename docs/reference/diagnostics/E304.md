# E304 Field in a transparent rule

A transparent rule `?name` has a field in an alternative without an alias. A transparent rule makes no node when it has one visible child, which would leave the field without a node to belong to.

```fpeg
start: value
?value: key=NAME "=" NAME | NAME
NAME: [a-z]+
```

```text
grammar.fpeg:2:2: error[E304]: the transparent rule value has a field outside an aliased alternative
```

Give the alternative an alias, which always makes a node.

```fpeg
start: value
?value: key=NAME "=" NAME -> pair | NAME
NAME: [a-z]+
```
