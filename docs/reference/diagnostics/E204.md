# E204 Defined twice

A rule or a level of a precedence block is defined twice, or a level has the name of a rule. Rules and levels share one set of names.

```fpeg
start: "a"
start: "b"
```

```text
grammar.fpeg:2:1: error[E204]: the rule start is defined twice
```

Give the rule all its alternatives in one definition, or rename one of them.

```fpeg
start: "a" | "b"
```
