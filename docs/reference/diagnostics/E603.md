# E603 Imported and defined

The grammar imports a rule from another grammar and defines a rule of the same name itself, so a reference could mean either.

```fpeg
%import common (NUMBER)
start: NUMBER+
NUMBER: [0-9]+
%ignore " "+
```

```text
grammar.fpeg:1:17: error[E603]: the grammar defines NUMBER, which it imports from common too
```

Keep one of them: the import, or the rule of the grammar.

```fpeg
%import common (NUMBER)
start: NUMBER+
%ignore " "+
```
