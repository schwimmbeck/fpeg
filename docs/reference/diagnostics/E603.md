# E603 Imported and defined

The grammar imports a rule from another grammar and has a rule of the same name already, defined, inherited or imported from a third grammar, so a reference could mean either.

```fpeg
%import common (NUMBER)
start: NUMBER+
NUMBER: [0-9]+
%ignore " "+
```

```text
grammar.fpeg:1:17: error[E603]: the grammar has a rule NUMBER already, which it imports from common too
```

Keep one of them: the import, or the rule of the grammar.

```fpeg
%import common (NUMBER)
start: NUMBER+
%ignore " "+
```
