# E305 Field over several items

A field can capture more than one visible item in one match. A field holds one item per match, so code reading it by name always knows what it gets.

```fpeg
start: pair=(NAME "=" NAME)
NAME: [a-z]+
```

```text
grammar.fpeg:1:8: error[E305]: the field pair can capture several items in one match
```

Give each item a field of its own, or make the items a node of their own.

```fpeg
start: key=NAME "=" value=NAME
NAME: [a-z]+
```
