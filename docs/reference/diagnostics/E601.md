# E601 Unknown grammar

The grammar extends a grammar that no module provides. The grammars that come with fpeg are `json` and `python`.

```fpeg
%extends "jsn"
?value: array | INT | NAME
NAME: [a-z]+
```

```text
grammar.fpeg:1:10: error[E601]: no grammar is named jsn
```

Name a grammar that exists.

```fpeg
%extends "json"
?value: array | INT | NAME
NAME: [a-z]+
```
