# E601 Unknown grammar

The grammar extends or imports a grammar that no module provides, or names a module in a way no module can be named, or one whose file cannot be read, as a file that is no UTF-8. A module name is plain: a letter, then letters, digits and underscores. The grammars that come with fpeg are `common`, `json` and `python`.

```fpeg
%extends "jsn"
?value: ... | NAME
NAME: [a-z]+
```

```text
grammar.fpeg:1:10: error[E601]: no grammar is named jsn
```

Name a grammar that exists.

```fpeg
%extends "json"
?value: ... | NAME
NAME: [a-z]+
```
