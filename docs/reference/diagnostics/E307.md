# E307 Character class

A character class has a range that runs backwards or lists nothing, as `[^]` does, or `%word` is given something other than a class.

```fpeg
start: [z-a]
```

```text
grammar.fpeg:1:8: error[E307]: the range 'z'-'a' runs backwards
```

Write each range from its first to its last code point.

```fpeg
start: [a-z]
```
