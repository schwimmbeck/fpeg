# E501 Not supported yet

The grammar uses a form that the language defines but fpeg does not run yet. The message names the milestone of the [roadmap](../../roadmap.md) that brings it:

- left recursion, such as a precedence block with an operator whose left operand is its own level, and cuts `~`: M4,
- `%indent`, `%same`, `%def` and `%ref`: M6,
- `%import`, `%extends` and `...`: M7,
- `%recover`: M8.

```fpeg
start: start "a" | "a"
```

```text
grammar.fpeg:1:1: error[E501]: the rule start is left recursive, which the parser does not run yet, see the roadmap (M4)
```

Until then, write the grammar without the form, here with a repetition.

```fpeg
start: "a"+
```
