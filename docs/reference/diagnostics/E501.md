# E501 Not supported yet

The grammar uses a form that the language defines but fpeg does not run yet. The message names the milestone of the [roadmap](../../roadmap.md) that brings it:

- `%import` under a prefix, `as`: M9,
- `...` in a precedence block, or for one: M9.

```fpeg
%import common as c
start: "a"+
%ignore " "+
```

```text
grammar.fpeg:1:19: error[E501]: an import under a prefix is not supported yet, see the roadmap (M9)
```

Until then, write the grammar without the form, here with the rules it takes named.

```fpeg
%import common (INT)
start: INT+
%ignore " "+
```
