# E501 Not supported yet

The grammar uses a form that the language defines but fpeg does not run yet. The message names the milestone of the [roadmap](../../roadmap.md) that brings it:

- `%indent`, `%same`, `%def` and `%ref`: M6,
- `%import`, `%extends` and `...`: M7,
- `%recover`: M8.

```fpeg
start: (%same NAME)+
NAME: [a-z]+
%ignore [ \n]+
```

```text
grammar.fpeg:1:1: error[E501]: the rule start uses %indent or %same, which the parser does not run yet, see the roadmap (M6)
```

Until then, write the grammar without the form.

```fpeg
start: NAME+
NAME: [a-z]+
%ignore [ \n]+
```
