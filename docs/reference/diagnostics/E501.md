# E501 Not supported yet

The grammar uses a form that the language defines but fpeg does not run yet. Two forms wait for a release after the first, as the [roadmap](../../roadmap.md) lists them under Later:

- `%import` under a prefix, `as`,
- `...` in a precedence block, or for one.

```fpeg
%import common as c
start: "a"+
%ignore " "+
```

```text
grammar.fpeg:1:19: error[E501]: an import under a prefix is not supported yet
```

Until then, write the grammar without the form, here with the rules it takes named.

```fpeg
%import common (INT)
start: INT+
%ignore " "+
```
