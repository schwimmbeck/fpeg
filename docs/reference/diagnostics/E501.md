# E501 Not supported yet

The grammar uses a form that the language defines but fpeg does not run yet. Three forms are [planned](../../planned.md) for a later release:

- `%import` under a prefix, `as`,
- `...` in a precedence block, or for one,
- the attribute `@sync`, where recovery may resume.

```fpeg
%import common as c
start: "a"+
%ignore " "+
```

```text
grammar.fpeg:1:19: error[E501]: an import under a prefix is not supported yet
```

Until then, write the grammar without the form, here with the rules it takes named.

```fpeg
%import common (INT)
start: INT+
%ignore " "+
```
