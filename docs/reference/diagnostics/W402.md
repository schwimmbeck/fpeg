# W402 Parameter that its rule never uses

A rule with parameters names one that its body never refers to. Every use of the rule still has to give an argument for it, and the argument is dropped. Mostly the body was meant to use it, or it is left over from an earlier form of the rule.

```fpeg
start: list<NAME, ",">
list<item, separator>: item ("," item)*
NAME: [a-z]+
```

```text
grammar.fpeg:2:12: warning[W402]: list never uses its parameter separator
```

Use the parameter, or remove it from the rule and from every use.

```fpeg
start: list<NAME, ",">
list<item, separator>: item (separator item)*
NAME: [a-z]+
```
