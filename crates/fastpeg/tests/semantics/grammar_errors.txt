=== an unknown rule is an error
start: missing
--- grammar
unknown rule missing

=== a rule defined twice is an error
start: "a"
start: "b"
--- grammar
the rule start is defined twice

=== a rule defined twice is an error also in a grammar with templates
start: t<"a">
start: "b"
t<x>: x
--- grammar
the rule start is defined twice

=== a parameter given arguments inside an argument is an error, not a rule of that name
start: t<"a">
t<x>: u<x<"b">>
u<y>: y
x<z>: z
--- grammar
the parameter x takes no arguments

=== a template used with the wrong number of arguments is an error
start: list<N>
list<item, sep>: item (sep item)*
N: [0-9]
--- grammar
list takes 2 arguments, 1 given

=== a terminal cannot use a syntactic rule
start: T
T: "a" inner
inner: "b"
--- grammar
cannot use the rule inner

=== the skip expression cannot use a syntactic rule
start: "a"
inner: "b"
%ignore inner
--- grammar
cannot use the rule inner

=== a tab width must lie between 1 and the maximum
%tabs 3000000000
start: "a"
--- grammar
%tabs needs a width from 1 to 1000

=== a hex escape in a class needs two hex digits
start: [\xaé]
--- grammar
invalid escape

=== a hex escape takes no sign
start: "\x+a"
--- grammar
invalid escape

=== a transparent rule cannot have fields
?start: x="a"
--- grammar
has a field

=== a field that can capture several items in one match is an error
start: x=(A | B C)*
A: "a"
B: "b"
C: "c"
--- grammar
the field x can capture several items in one match

=== a field over an inlined rule counts the items the rules it calls add
start: x=_outer
_outer: _pair
_pair: A B
A: "a"
B: "b"
--- grammar
the field x can capture several items in one match

=== an alternative with fields in a precedence block needs an alias
start: expr
expr: %precedence {
    sum: left=sum "+" right=atom
    atom: N
}
N: [0-9]
--- grammar
needs -> in a precedence block

=== a level name may not shadow a rule
start: expr
expr: %precedence {
    start: N

--- grammar
the level start shadows a rule

=== imports are not supported yet
%import common (WS)
start: "a"
--- grammar
%import is not supported yet

=== extending, recovery and a word set that is no class are errors, and builders print back
%extends "base"
%import common (WS, INT) as c
%word "a"
%recover missing: (!";" .)*
start: "a" => Point(x, y=*, z=None, w="s", n=1.5)
    | "b" => text
    | "c" => 42
    | "d" => True
--- grammar
%extends is not supported yet
%recover is not supported yet
%word needs a character class

=== a repetition maximum below its minimum is an error
start: "a"{3,2}
--- grammar

=== a repetition count must fit in 32 bits

--- grammar

=== only terminals can be reserved, and a terminal is neither transparent nor aliased
@reserved
start: T U
?T: "a"
U: "b" -> u
--- grammar
only terminals can be @reserved, not start
the terminal T cannot be transparent
the terminal U cannot have an alias

=== a precedence block is a plain syntactic rule without parameters
start: _e t<"x">
_e: %precedence {
    a: "a"
}
t<p>: %precedence {
    b: p
}
--- grammar
the precedence block _e must be a plain syntactic rule
the precedence block t cannot have parameters

the level b takes no arguments
