=== an unknown rule is an error
start: missing
--- grammar
unknown rule missing

=== a rule defined twice is an error
start: "a"
start: "b"
--- grammar
the rule start is defined twice

=== a template used with the wrong number of arguments is an error
start: list<N>
list<item, sep>: item (sep item)*
N: [0-9]
--- grammar
list takes 2 arguments, 1 given

=== a terminal cannot use a syntactic rule
start: T
T: "a" inner
inner: "b"
--- grammar
cannot use the rule inner

=== the skip expression cannot use a syntactic rule
start: "a"
inner: "b"
%ignore inner
--- grammar
cannot use the rule inner

=== a hex escape in a class needs two hex digits
start: [\xaé]
--- grammar
invalid escape

=== a hex escape takes no sign
start: "\x+a"
--- grammar
invalid escape

=== a transparent rule cannot have fields
?start: x="a"
--- grammar
has a field

=== a field that can capture several items in one match is an error
start: x=(A | B C)*
A: "a"
B: "b"
C: "c"
--- grammar
the field x can capture several items in one match

=== a field over an inlined rule counts the items the rule adds
start: x=_pair
_pair: A B
A: "a"
B: "b"
--- grammar
the field x can capture several items in one match

=== an alternative with fields in a precedence block needs an alias
start: expr
expr: %precedence {
    sum: left=sum "+" right=atom
    atom: N
}
N: [0-9]
--- grammar
needs -> in a precedence block

=== a level name may not shadow a rule
start: expr
expr: %precedence {
    start: N
}
N: [0-9]
--- grammar
