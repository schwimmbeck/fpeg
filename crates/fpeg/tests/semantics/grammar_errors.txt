=== an unknown rule is an error
start: missing
--- grammar
unknown rule missing

=== a rule defined twice is an error
start: "a"
start: "b"
--- grammar
the rule start is defined twice

=== a rule defined twice is an error also where it replaces an inherited one
%extends "json"
?value: INT
?value: STRING
--- grammar
the rule value is defined twice

=== a rule defined twice is an error also in a grammar with templates
start: t<"a">
start: "b"
t<x>: x
--- grammar
the rule start is defined twice

=== a parameter declared twice is an error
start: t<"x", "y">
t<a, a>: a
--- grammar
the parameter a of the rule t is declared twice

=== a parameter given arguments inside an argument is an error, not a rule of that name
start: t<"a">
t<x>: u<x<"b">>
u<y>: y
x<z>: z
--- grammar
the parameter x takes no arguments

=== a template used with the wrong number of arguments is an error
start: list<N>
list<item, sep>: item (sep item)*
N: [0-9]
--- grammar
list takes 2 arguments, 1 given

=== a terminal cannot use a syntactic rule

=== the skip expression cannot use a syntactic rule
start: "a"
inner: "b"

--- grammar

=== a tab width must lie between 1 and the maximum
%tabs 3000000000

=== a grammar gives its tab width and its word characters once
%tabs 4
%tabs 8
%word [a-z]

a grammar says its word characters once

=== a level name is a name of the whole grammar, so no rule or other level may have it

the level atom is defined twice

=== a word set that is no class is an error in a grammar that extends and imports others, and recoveries and builders print back

    | "b" => text
    | "c" => 42
    | "d" => True
--- grammar
%word needs a character class

=== only terminals can be reserved, and a terminal is neither transparent nor aliased

=== a terminal or the skip expression cannot use a level

a terminal or the skip expression cannot use the level atom
